# 🎸 Гриф — магазин электрогитар

## Описание
Сайт-визитка магазина электрогитар на чистом HTML, CSS и JavaScript. Учебный проект: Git, ветки main и test, деплой на GitHub Pages.

## 🚀 Функциональность
- [x] Адаптивный дизайн (Mobile First, меню-бургер на телефоне)
- [x] Тёмная и светлая тема (запоминается в localStorage)
- [x] Навигация между страницами с подсветкой активной ссылки
- [x] Каталог (37 позиций) с фильтром по категориям и поиском
- [x] Поиск по статьям блога
- [x] Избранное для гитар (localStorage)
- [x] Форма обратной связи, сообщения сохраняются в localStorage
- [x] JS-эффекты: звенящие струны в hero (наведи курсор)

## 📁 Структура проекта
```
my-web-site/
├── index.html      главная
├── about.html      о нас
├── shop.html       каталог гитар, усилителей и педалей
├── blog.html       блог с поиском
├── contact.html    контакты и форма
├── css/style.css   стили и темы
├── js/catalog.js   данные и фильтры каталога
├── js/script.js    тема, избранное, поиск, форма
├── img/            логотип, favicon, заглушки
│   └── guitars/    фото товаров (имя файла = id из catalog.js)
└── README.md
```
